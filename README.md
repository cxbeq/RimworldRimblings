This Rimworld mod adds "Animalese" style pawn speech! Think the dialogue in Animal Crossing or other JRPGs.

Requires the Harmony mod.

Grab Rimlings here!! https://steamcommunity.com/sharedfiles/filedetails/?id=3806903620&

You'll be able to hear their little ramblings whenever they have a social interaction.

Voices are given based on gender, age, and body. This works with other mods like Jaxe's 'Interaction Bubbles', and lets you put a voice to each speech bubble.

SpeakUp for RimWorld 1.6 is supported. Load Interaction Bubbles and SpeakUp before Rimblings. Rimblings voices SpeakUp's opening lines and replies using the text resolved for each bubble, without generating extra dialogue or scheduling replies itself. With SpeakUp enabled, two-pawn speech follows bubble text generation; turning bubbles off also silences those lines. Existing hearing, volume, cooldown and simultaneous-voice settings still apply. SpeakUp and Interaction Bubbles remain optional.

Configurable options include:

- Pawn speech on or off, and whether visitors, raiders, and other nearby humanlike pawns speak.
- Speech volume and shorter speech using each word’s first and last letters.
- How voices fade with camera zoom, plus the hearing radius around the camera.
- How loud background voices remain when a speaker is focused.
- An optional cap on simultaneous voices, with an adjustable limit.
- A reset to default settings.
- A Voice Editor on the main toolbar, with per-pawn pitch, depth, speed, tone, recording bank and audio previews. The toolbar button can be hidden in mod settings.

Open **Voice Editor**, select one of your colony's colonists, adjust the controls and use **Preview voice** to hear the draft. Colonists on other maps or travelling in caravans are included; visitors, prisoners and temporary quest guests are excluded. **Save voice** applies it to the current game. Save the game afterward to retain it; loading an earlier save restores that save's voices. **Restore generated voice**, followed by **Save voice**, removes the pawn's override.

Voice overrides belong to the colony save, not a global configuration file. Existing saves and new games use generated voices until you edit a pawn. Removing Rimblings leaves pawn gameplay data unchanged; RimWorld can report its missing game component when loading, then discard the voice data when you save without the mod. Re-enabling Rimblings on that save generates voices again. The editor does not require Character Editor.
